# Digital Twin EAM (Enterprise Asset Management)

## Vision
Digital Twin EAM is an industrial asset management system designed around Digital Twin concepts and built for compliance with ISO 55001 and ISO 14224. The project aims to deliver robust, auditable, and scalable management of industrial assets, supporting best practices in reliability, maintenance, and operational excellence.

## Tech Stack
- .NET
- PostgreSQL
- Azure
- PlantUML
- BPMN

## Folder Structure
| Folder           | Purpose                                                                                       |
|------------------|-----------------------------------------------------------------------------------------------|
| `bpmn/`          | Business process models (e.g., maintenance cycles) that define the core operational logic.     |
| `domain-models/` | Conceptual models of the software, including class diagrams and use cases for system behavior. |
| `compliance/`    | Regulatory shield: mappings and justifications for ISO 14224/55001 compliance.                |
| `assets/`        | Supplementary resources: database schemas (CSV), interview transcripts, and requirements data. |
