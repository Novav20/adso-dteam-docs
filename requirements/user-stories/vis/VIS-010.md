# VIS-010: Exploded View Visualization

## Story Description

| Role | Action | Benefit |
|---|---|---|
| Maintenance Technician | I want to visualize the exploded view (breakdown) of the selected equipment unit in 3D. | So that I can identify the exact location of an internal component before starting physical disassembly. |

## Acceptance Criteria
| Scenario | Given (Context) | When (Action) | Then (Result) |
|---|---|---|---|
| Exploded View Activation | Given the Technician has selected a pump in the viewer and the exploded model is available. | When they select the 'View Exploded' option. | Then the model parts separate visually with a fluid animation, allowing internal components like the shaft and bearings to be seen. |
| Internal Component Selection | Given the equipment unit is in 'Exploded View' mode. | When the Technician selects a specific bearing. | Then the system highlights the component and displays a card with its name, part code, and inventory availability at the time of query. |
| 3D Model unavailable (Graceful Degradation) | Given the Technician selects an equipment unit whose exploded model is not loaded in the repository. | When they attempt to activate the 'View Exploded' option. | Then the system displays a clear notice that the model is unavailable without blocking access to the rest of the details panel. |
