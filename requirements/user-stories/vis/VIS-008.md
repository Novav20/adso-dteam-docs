# VIS-008: Work Permit Layer Visualization

## Story Description

| Role | Action | Benefit |
|---|---|---|
| HSEQ Inspector | I want to enable a visual layer showing active work permits on the 2D/3D Digital Twin. | So that I can quickly identify dangerous crossings of activities and avoid accidents due to interference between contractors. |

## Acceptance Criteria
| Scenario | Given (Context) | When (Action) | Then (Result) |
|---|---|---|---|
| Safety layer activation (Visual Redundancy) | Given the Inspector is viewing the general plant map (Level 1). | When they activate the 'Work Permits' layer. | Then the system overlays icons over the affected equipment units, using redundant coding (Color + Shape): Hot Work: Red Square. Working at Heights: Blue Triangle. Confined Space: Yellow Circle. |
| Contextual Query (Information Breakdown) | Given a 'Hot Work' icon is shown over pump P-202. | When the Inspector clicks on the icon. | Then a compact card is displayed (without obscuring context) with: Contractor, Start/End Time, and HSEQ Responsible. |
| Integrity Validation (Orphan Detection) | Given there is an active Work Permit associated with Tag 'V-101'. | When the system attempts to render the icon in the 2D/3D Digital Twin and detects that the object 'V-101' does not exist in the current geometry or layout (Broken Link). | Then the system generates a 'Compromised Safety Integrity' alert in the notification panel and displays the permit in a lateral 'Visualization Failures' list so it does not go unnoticed. |
