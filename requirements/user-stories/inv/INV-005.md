# INV-005: Equipment Unit Technical Record Creation

## Story Description

| Role | Action | Benefit |
|---|---|---|
| Project Engineer | I want to create the digital technical record of a new physical equipment unit with its identification data and minimum operational parameters. | So that I can have an official master record that allows life cycle traceability, linkage to maintenance plans, and the capture of failure history. |

## Acceptance Criteria
| Scenario | Given (Context) | When (Action) | Then (Result) |
|---|---|---|---|
| Successful creation with minimum fields | Given the Project Engineer is on the new equipment unit registration interface. | When they fill out the mandatory technical fields (identification, class, manufacturer, and operational dates) and request to save. | Then the system formalizes the equipment unit registration, communicates the operation's success, and presents the newly created equipment's technical record. |
| Duplicate Tag prevention | Given the industrial identifier (Tag) is already assigned to an existing equipment unit in the system. | When the technical staff attempts to register a new equipment unit using the same identifier. | Then the system issues a warning notification indicating the identifier is already in use and suggests reviewing the existing record. |
| Mandatory fields validation | Given the creation of a new operational equipment unit is underway. | When the user attempts to finalize the registration omitting mandatory technical classification (e.g. Equipment Class). | Then the system restricts the save action, highlights missing fields, and notifies about the failure to comply with ISO 14224 information requirements. |
| Date coherence validation | Given the technical staff enters the equipment's operational chronology. | When an operation start date is registered that is prior to the equipment's acquisition or purchase date. | Then the system detects the temporal inconsistency and communicates an integrity warning to ensure historical data accuracy. |
