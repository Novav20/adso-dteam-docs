# INV-025: Equipment Swap

## Story Description

| Role | Action | Benefit |
|---|---|---|
| Project Engineer | I want to unlink a physical equipment unit from its functional location and install an identical replacement equipment from the inventory. | So that I can preserve the accumulated reliability history in the operational position, record the change of location of the physical machine, and update the state of rotable spare parts in a traceable manner. |

## Acceptance Criteria
| Scenario | Given (Context) | When (Action) | Then (Result) |
|---|---|---|---|
| Successful equipment unit swap | Given a Functional Location has an assigned physical equipment unit (A) and an identical replacement unit (B) is available in the warehouse. | When the user executes the swap action, associating it to a Work Order. | Then the system unlinks unit (A) setting its status to 'In Repair', links unit (B) to the location setting it to 'Operational', and logs the structural audit transaction. |
| Swap blocked due to non-operational replacement | Given the user selects a replacement equipment unit from inventory. | When said unit is in 'Damaged' or 'Decommissioned' status, or already assigned elsewhere. | Then the system blocks the swap process, issues an incompatibility alert, and does not alter the location's configuration. |
| Historical Traceability log | Given a successful equipment unit swap was completed. | When the technical history of the Functional Location is queried. | Then the system presents a timeline of all physical equipment units installed at that operational position, detailing installation and removal dates. |
