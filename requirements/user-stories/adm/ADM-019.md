# ADM-019: Data Synchronization with BI Tools

## Story Description

| Role | Action | Benefit |
|---|---|---|
| Plant Manager | I want to export or synchronize KPI data directly with external tools (like Power BI or Excel). | So that I can have management presentations always updated and perform deep analysis without having to manually copy and paste charts every month. |
