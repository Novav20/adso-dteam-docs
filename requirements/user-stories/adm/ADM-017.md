# ADM-017: Executive KPIs Dashboard

## Story Description

| Role | Action | Benefit |
|---|---|---|
| Plant Manager | I want to view an Executive Dashboard with key KPIs (MTBF, Costs, Availability) allowing filtering by date and area. | So that I can identify failure trends and "Bad Actors" to direct the maintenance budget where it is needed most. |

## Acceptance Criteria
| Scenario | Given (Context) | When (Action) | Then (Result) |
|---|---|---|---|
| Announcement Expiration | Given a global announcement has a defined expiration date. | When the system clock surpasses the expiration date. | Then the system automatically hides the announcement from all user dashboards. |
| KPI Dashboard filtering by date range | Given the Plant Manager is viewing the Executive Dashboard. | When they adjust the date range filter to the 'Last Quarter'. | Then the MTBF and MTTR metrics automatically recalculate to reflect only that specific period. |
| KPI Dashboard filtering by Technical Class | Given the Executive Dashboard is loaded. | When the user filters by the 'Centrifugal Pumps' technical class. | Then the displayed charts and metrics isolate the reliability data exclusively for those equipment units. |
