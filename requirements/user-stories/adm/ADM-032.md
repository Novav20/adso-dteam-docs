# ADM-032: Immutable Audit System

## Story Description

| Role | Action | Benefit |
|---|---|---|
| Plant Manager | I want to consult a chronological and unalterable record of all critical actions performed in the system (Creation, Modification, Deletion). | So that I can reconstruct the sequence of events in the event of an incident and demonstrate regulatory compliance (ISO 55001 / ISO 14224). |

## Acceptance Criteria
| Scenario | Given (Context) | When (Action) | Then (Result) |
|---|---|---|---|
| Critical Data Modification capture | Given a Planner changes a Work Order's 'Priority' from 'High' to 'Low'. | When they save the changes. | Then the system automatically logs an audit entry detailing: Who, When, Entity, and the specific field change from 'High' to 'Low'. |
| Query Equipment Unit Audit History | Given the Auditor is investigating the history of equipment unit 'Pump P-101'. | When they filter the audit log by the specific entity ID. | Then they view a complete timeline of all status changes, maintenance, and attribute modifications since its creation. |
| Soft-delete traceability | Given a user attempts to delete a 'Spare Part' record from the master inventory. | When they confirm the action. | Then the system marks the record as inactive (Soft-Delete) and creates a 'DELETE_ATTEMPT' audit entry with the provided justification. |
