# ADM-013: Role and Permission Matrix Management (Industrial RBAC)

## Story Description

| Role | Action | Benefit |
|---|---|---|
| System Administrator | I want to define user roles with a granular permission matrix (Create, Edit, Delete, Approve, Close, Audit). | So that I can ensure the segregation of duties required by ISO 55001 and prevent the same user from requesting and approving critical actions. |

## Acceptance Criteria
| Scenario | Given (Context) | When (Action) | Then (Result) |
|---|---|---|---|
| Custom Role Definition | Given the Administrator is in the roles module. | When they create a new role 'External Auditor' and select only 'Read' permissions for Work Orders. | Then the system saves the role, ensuring any assigned user cannot modify or create records. |
| Attempt to exceed granted permissions | Given a user with a 'Technician' role is authenticated. | When they attempt to access the 'Settings' module via URL manipulation. | Then the system rejects the access and displays a 403 Forbidden error, logging the security event. |
| Revoke active permissions | Given an active user is logged in. | When the Administrator immediately revokes their permissions from the dashboard. | Then the user is automatically logged out or blocked upon their next system interaction. |
