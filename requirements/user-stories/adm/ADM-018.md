# ADM-018: PDF Report Export

## Story Description

| Role | Action | Benefit |
|---|---|---|
| Plant Manager | I want to download a PDF report with key maintenance indicators (MTBF, MTTR, Availability). | So that I can analyze monthly performance and present it in management meetings without depending on a system connection. |

## Acceptance Criteria
| Scenario | Given (Context) | When (Action) | Then (Result) |
|---|---|---|---|
| Schedule automatic report via Email | Given the Plant Manager configures a monthly KPI report. | When they set the delivery email and schedule it for the first day of the month. | Then the system automatically generates the PDF and sends it via email at the scheduled date and time. |
| Failed report export due to missing data | Given the Manager attempts to download a report for a specific month. | When the system detects insufficient records to calculate the indicators. | Then it displays an error message stating there is no data available to generate the report. |
