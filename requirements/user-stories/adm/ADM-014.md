# ADM-014: User Management and Secure Life Cycle

## Story Description

| Role | Action | Benefit |
|---|---|---|
| System Administrator | I want to manage the entire user life cycle (Create, Suspend, Restore, Reset Password) securely and auditably. | So that I can protect access to the Digital Twin and ensure the traceability of actions performed by former employees. |

## Acceptance Criteria
| Scenario | Given (Context) | When (Action) | Then (Result) |
|---|---|---|---|
| Disable inactive users | Given an employee contract has ended. | When the Administrator marks the user profile as 'Inactive'. | Then the user's login credentials are disabled, but their associated historical records and audits remain intact. |
| Successful login | Given a user has valid credentials. | When they input their username and password in the portal. | Then the system authenticates the session and redirects them to their role-specific dashboard. |
| Locked account after failed attempts | Given a user enters incorrect passwords multiple times. | When they reach the maximum threshold of 5 failed attempts. | Then the system locks the account temporarily and sends an alert to the Administrator. |
