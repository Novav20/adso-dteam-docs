# ADM-024: General System Configuration

## Story Description

| Role | Action | Benefit |
|---|---|---|
| System Administrator | I want to configure global system parameters (e.g., Company Logo, Time Zone, Units of Measurement). | So that I can customize the platform according to the plant's identity and location without modifying the code. |

## Acceptance Criteria
| Scenario | Given (Context) | When (Action) | Then (Result) |
|---|---|---|---|
| Change Corporate Logo | Given the Administrator is in the 'General Settings' screen. | When they upload an image file (PNG/JPG) into the 'Corporate Logo' field and save. | Then the logo in the top navigation bar immediately updates to reflect the new image. |
| Change System Time Zone | Given the Administrator is in regional settings and the current time is UTC. | When they select 'UTC-5 (Colombia)' from the dropdown list. | Then all dates and times shown on Work Orders automatically adjust to the newly selected zone. |
