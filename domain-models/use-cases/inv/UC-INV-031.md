# UC-INV-031: Manage Spare Part Master Catalog (Part Master)

## Use Case Template

| **Element** | **Detail** |
| :--- | :--- |
| **ID** | UC-INV-031 |
| **Name** | Manage Spare Part Master Catalog (Part Master) |
| **Primary Actor** | Warehouse Manager |
| **Secondary Actors** | N/A |
| **Description** | Allows the standardized creation, update, and technical categorization of materials and spare parts in the master catalog (Part Master), preventing duplicates and ensuring that inventory policies (Min/Max, Reorder Point, Just in Time) and unit costs are accurately configured to automate replenishment generation and accurate valuation of Work Orders. |
| **Preconditions** | <ul><li>The Warehouse Manager is authenticated in the system with the appropriate role [[TR-006]].</li><li>The standard catalog of manufacturers and generic Material commodity codes is available.</li></ul> |
| **Main Flow** | 1. The Warehouse Manager accesses the Spare Parts Catalog menu and selects the "New Spare Part" option.<br>2. The System displays the registration form demanding the following mandatory fields:<br>   - SKU / Unique Code.<br>   - Technical description and Commodity Code.<br>   - Manufacturer and reference Model.<br>   - Material Hierarchical Category (ISO 14224) and Standardized Equipment Class (optional).<br>   - Unit of Measure (UoM).<br>   - Special indicators: Repairable Spare (Rebuildable) and Safety Critical Equipment Spare (SCE).<br>   - Inventory Policy (Reorder Point, Min/Max, JIT).<br>   - Reorder Point (Critical trigger quantity) and Maximum Warehouse Capacity.<br>   - Estimated Unit Cost.<br>3. The Warehouse Manager enters the data of a high-precision bearing, checks the "Repairable Spare" box, and enters the SKU "SKF-6204".<br>4. The System executes an automatic redundancy and uniqueness analysis against the master database catalog:<br>   - Validates that the SKU "SKF-6204" is not exactly duplicated.<br>   - Executes a semantic and phonetic search filter over the descriptions of existing spares to identify potential duplicate records with alternate names.<br>5. The System confirms the validity of the data and configures the stock monitoring rules according to the chosen policy.<br>6. The Warehouse Manager confirms saving the spare part.<br>7. The System permanently and uniquely registers the new spare part in the database's master material catalog, recording creation attributes (user, timestamp, registered SKU, manufacturer, stock policy, and parameterized cost).<br>8. The System displays a confirmation message of successful registration. |
| **Alternate Flows** | **AF-001: Potential Duplicate Record Detected (Redundant Coding)**<br>In step 4, if the system detects that a spare part with matching characteristics already exists (e.g. a description "Radial Bearing SKF 6204" with a similar SKU):<br>   1. The System interrupts the saving and displays a warning using redundant Shape + Color coding (alert symbol + contrast indicator) according to WCAG 2.1 AA: "Potential duplicate detected: The catalog already has a spare part with similar characteristics (SKU: SKF-6204-A). Do you want to cancel the creation or justify the registration of the new SKU?"<br>   2. If the user decides to cancel, the flow is canceled.<br>   3. If the user justifies the technical need for the new SKU, they enter a mandatory justification and the system continues to step 6, recording the justification in the catalog change record.<br><br>**AF-002: Direct Purchase Classification (No Storage)**<br>In step 3, if the Warehouse Manager defines the inventory type as direct purchase ("Direct Purchase / JIT"):<br>   1. The System dynamically adapts the interface, hiding the mandatory storage fields (shelf location, maximum capacity, and reorder point).<br>   2. The flow continues to step 6. |
| **Postconditions** | <ul><li>The new spare part is registered in the Part Master uniquely and standardized, ready to be consumed in Work Orders.</li><li>Replenishment policies and ABC classification are associated and active for the stock monitor rules.</li></ul> |
| **Associated Requirements** | FR-170, FR-171, FR-172, FR-173, FR-174, FR-175, FR-176, FR-181, NFR-177, NFR-178, NFR-179, NFR-180, [[TR-008]] |
