# UC-INV-031: Gestión de Catálogo de Repuestos Maestro (Part Master)

## Plantilla de Caso de Uso

| **Elemento** | **Detalle** |
| :--- | :--- |
| **ID** | UC-INV-031 |
| **Nombre** | Gestión de Catálogo de Repuestos Maestro |
| **Actor Principal** | Jefe de Almacén |
| **Actores Secundarios** | Auditor Externo (lector) |
| **Descripción** | Permite al Jefe de Almacén registrar y parametrizar la información técnica y las políticas de inventario de nuevos repuestos en el catálogo maestro, clasificándolos jerárquicamente e implementando un filtro de seguridad contra duplicados. |
| **Precondiciones** | <ul><li>El Jefe de Almacén está autenticado con el rol de "Jefe de Almacén".</li><li>Las clasificaciones de familias y categorías de materiales están parametrizadas en la base de datos según la norma ISO 14224.</li></ul> |
| **Flujo Principal** | 1. El Jefe de Almacén accede al menú del Catálogo de Repuestos y selecciona la opción "Nuevo Repuesto".<br>2. El Sistema despliega el formulario de registro exigiendo el ingreso de los siguientes campos obligatorios:<br>&nbsp;&nbsp;&nbsp;- SKU / Código Único.<br>&nbsp;&nbsp;&nbsp;- Descripción técnica.<br>&nbsp;&nbsp;&nbsp;- Fabricante / Modelo.<br>&nbsp;&nbsp;&nbsp;- Categoría Jerárquica de Material (ISO 14224).<br>&nbsp;&nbsp;&nbsp;- Unidad de Medida (UoM).<br>&nbsp;&nbsp;&nbsp;- Política de Inventario (Dropdown: "Punto de Reorden", "Min/Max", "JIT").<br>&nbsp;&nbsp;&nbsp;- Punto de Reorden (Cantidad crítica de disparo).<br>&nbsp;&nbsp;&nbsp;- Costo Unitario Estimado.<br>3. El Jefe de Almacén ingresa los datos de un rodamiento de alta precisión e introduce el SKU "SKF-6204".<br>4. El Sistema ejecuta un análisis automático de redundancia y unicidad contra los registros existentes en la base de datos:<br>&nbsp;&nbsp;&nbsp;- Valida que el SKU "SKF-6204" no esté duplicado de forma exacta.<br>&nbsp;&nbsp;&nbsp;- Ejecuta un filtro de búsqueda semántica y fonética sobre las descripciones de los repuestos existentes para identificar posibles registros duplicados con nombres alternos.<br>5. El Sistema confirma la validez de los datos y configura las variables dinámicas de inventario basadas en la política seleccionada.<br>6. El Jefe de Almacén guarda el registro del repuesto.<br>7. El Sistema:<br>&nbsp;&nbsp;&nbsp;- Inserta el nuevo ítem de forma permanente en la tabla `spare_parts`.<br>&nbsp;&nbsp;&nbsp;- Registra la operación en el rastro de auditoría inmutable [TR-001] capturando: usuario, timestamp, SKU registrado, fabricante, política de stock y costo parametrizado.<br>8. El Sistema muestra un mensaje de confirmación del registro exitoso. |
| **Flujos Alternativos** | **AF-001: Registro Duplicado Potencial Detectado**<br>En el paso 4, si el sistema detecta que ya existe un repuesto con características coincidentes (ej. un registro con descripción "Rodamiento Radial SKF 6204" y SKU similar):<br>1. El Sistema interrumpe el guardado y muestra una advertencia en la interfaz: "Duplicado potencial detectado: El catálogo ya cuenta con un repuesto de características similares (SKU: SKF-6204-A). ¿Desea anular la creación y utilizar el registro existente o forzar el alta de un nuevo SKU?"<br>2. Si el usuario decide anular, el flujo se cancela.<br>3. Si el usuario justifica la necesidad del nuevo SKU, ingresa una justificación técnica obligatoria y el sistema continúa en el paso 6, registrando el motivo del bypass en la auditoría.<br><br>**AF-002: Clasificación Direct Purchase (Sin Almacenamiento)**<br>En el paso 3, si el Jefe de Almacén define el tipo de inventario como compra directa ("Direct Purchase / JIT"):<br>1. El Sistema adapta dinámicamente la interfaz, ocultando los campos obligatorios de almacenamiento (ubicación en estantería, capacidad máxima y stock de seguridad).<br>2. El flujo continúa en el paso 6. |
| **Postcondiciones** | <ul><li>El nuevo repuesto queda registrado en el Part Master de forma única y estandarizada.</li><li>Las políticas de reabastecimiento y clasificación ABC quedan asociadas y activas para las reglas del monitor de stock.</li><li>La entrada transaccional del alta queda registrada en la tabla de auditoría protegida.</li></ul> |
| **Requisitos Asociados** | FR-170, FR-171, FR-172, FR-173, FR-174, FR-175, FR-176, [[TR-001]] |
