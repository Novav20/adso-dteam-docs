| **Descripción**          | Permite al Gerente de Planta y a auditores externos consultar y verificar el registro cronológico e inalterable de operaciones críticas ejecutadas en el sistema. El caso de uso valida la integridad del log de forma criptográfica (SHA-256 encadenado) a nivel de aplicación (ADR-003) para asegurar el no repudio y detectar modificaciones directas por SQL.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Precondiciones**       | <ul><li>El usuario está autenticado con un rol autorizado para auditoría ("Gerente de Planta" o "Auditor").</li><li>Existen registros históricos de auditoría guardados en el esquema de persistencia.</li></ul>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **Flujo Principal**      | 1. El Gerente de Planta accede al panel de "Seguridad y Auditoría" y selecciona "Consultar Registro de Cambios" (FR-348).<br>2. El Sistema presenta los parámetros de filtrado avanzado: rango de fechas, usuario responsable, tipo de operación DML (crear, modificar, eliminar) y tipo de entidad (ej. `WorkOrder`, `SparePart`) (FR-348).<br>3. El Gerente configura un filtro para auditar los cambios de prioridad sobre la orden de trabajo "WO-1052" en los últimos 30 días y confirma la consulta.<br>4. El Sistema realiza un query optimizado y recupera las filas de la tabla `audit_logs` en formato JSONB nativo de PostgreSQL (FR-349).<br>5. El Sistema presenta los resultados en una línea de tiempo estructurada. El Gerente selecciona la fila correspondiente al cambio de prioridad ejecutado por "Carlos.Gomez" (FR-349).<br>6. El Sistema abre el detalle de la auditoría mostrando de forma comparativa el estado del registro:<br>&nbsp;&nbsp;&nbsp;- Estado Anterior (`previousState`): `{"Priority": "Alta", "ScheduledDate": "2026-07-15"}`.<br>&nbsp;&nbsp;&nbsp;- Estado Nuevo (`newState`): `{"Priority": "Baja", "ScheduledDate": "2026-07-15"}` (FR-345).<br>7. El Sistema ejecuta de forma automática en el backend la rutina de validación de integridad criptográfica (`VerifyIntegrity()`):<br>&nbsp;&nbsp;&nbsp;- Recalcula de forma secuencial el hash SHA-256 del registro actual concatenando sus datos físicos con el valor de la columna `integrity_hash` de la fila inmediatamente anterior de la base de datos (ADR-003, FR-351).<br>&nbsp;&nbsp;&nbsp;- Compara el hash calculado con el hash persistido.<br>8. Al confirmar la coincidencia exacta de toda la cadena de hashes, el Sistema muestra en la pantalla de detalle una marca visual de seguridad: "Integridad Criptográfica Verificada: Registro Inalterado" (FR-351).<br>9. El Sistema registra la consulta en la tabla de auditoría como una acción de lectura administrativa de nivel de seguridad (meta-auditoría) [TR-001]. |
| **Flujos Alternativos**  | **AF-001: Alerta de Integridad Comprometida (Tamper-Evident Activation)**<br>En el paso 7, si la verificación de la cadena de hashes falla (es decir, un administrador de base de datos o intruso modificó directamente una fila mediante consola SQL saltándose la API):<br>1. El Sistema interrumpe la visualización de los detalles y bloquea de forma inmediata cualquier exportación de datos del rango de fecha afectado.<br>2. El Sistema activa una alerta roja prominente de prioridad de seguridad máxima en el panel: "ADVERTENCIA DE SEGURIDAD: Inconsistencia detectada en la cadena de auditoría. Posible manipulación física de datos." (FR-346).<br>3. El Sistema genera de forma automática un correo electrónico y alerta SMS de seguridad dirigidos al Auditor y al HSEQ, detallando el identificador del log comprometido.<br>4. El evento de fallo se registra en el log del sistema operativo (syslog) para análisis forense.<br><br>**AF-002: Rango de Consulta sin Resultados**<br>En el paso 4, si no existen registros bajo los filtros ingresados:<br>1. El Sistema muestra un mensaje descriptivo: "No se encontraron transacciones críticas en el rango seleccionado."<br>2. El flujo regresa al paso 2.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Postcondiciones**      | <ul><li>El auditor obtiene el rastro inalterable de los datos y su comparativa de estados.</li><li>La integridad del log queda validada mediante algoritmos criptográficos a nivel de aplicación (ADR-003).</li><li>Cualquier alteración o ruptura del historial encadenado de la base de datos es expuesta e informada de inmediato.</li></ul>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
