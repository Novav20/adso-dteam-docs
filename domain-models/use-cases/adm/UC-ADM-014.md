# UC-ADM-014: Administrar Ciclo de Vida de Usuarios

## Plantilla de Caso de Uso

| **Elemento**             | **Detalle**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| :----------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ID**                   | UC-ADM-014                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Nombre**               | Administrar Ciclo de Vida de Usuarios                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Actor Principal**      | Administrador del Sistema                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Actores Secundarios**  | Usuario (Autogestión), Servicio de Notificaciones                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Descripción**          | Permite gobernar el ciclo de vida completo de las cuentas de usuario garantizando el cumplimiento de la norma ISO 27001. Abarca la creación segura con verificación de identidad, la desactivación lógica para preservar el historial de auditoría, la recuperación de credenciales y la mitigación automática de ataques de fuerza bruta.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Precondiciones**       | <ul><li>El Administrador está autenticado con privilegios de gestión de identidad y accesos (IAM) [[TR-006]].</li><li>El servicio de envío asíncrono de correos electrónicos está operativo.</li></ul>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Flujo Principal**      | 1. El Administrador accede al panel de "Gestión de Usuarios" y selecciona "Registrar Nuevo Usuario".<br>2. El Administrador ingresa los datos institucionales (Nombre, Correo Electrónico) y asigna un rol funcional inicial.<br>3. El Sistema valida que el correo electrónico sea único en el registro.<br>4. El Sistema crea la cuenta en estado inactivo/pendiente.<br>5. El Sistema genera un token criptográfico de un solo uso con validez temporal limitada.<br>6. El Sistema despacha de forma asíncrona un correo electrónico al usuario con el enlace seguro de activación.<br>7. El Sistema registra la transacción de creación en la auditoría inmutable [[TR-001]] con su respectivo hash criptográfico encadenado.<br>8. (Fuera de banda) El Usuario accede al enlace, define una contraseña que cumpla con las políticas de complejidad parametrizadas y el Sistema activa la cuenta, invalidando el token de registro. |
| **Flujos Alternativos**  | **AF-001: Desactivación Segura (Borrado Lógico)**<br>Si el Administrador requiere remover a un usuario (ej. cese de contrato):<br>   1. El Administrador selecciona la cuenta activa y ejecuta la acción "Desactivar Usuario".<br>   2. El Sistema exige una justificación administrativa.<br>   3. El Administrador confirma la acción.<br>   4. El Sistema aplica un borrado lógico (cambia el estado a INACTIVO) preservando intactas las relaciones históricas del usuario en las órdenes de trabajo y logs de auditoría.<br>   5. El Sistema revoca e invalida de forma inmediata todas las sesiones y tokens de acceso activos de dicho usuario.<br>   6. El Sistema registra la desactivación en la auditoría inmutable [[TR-001]].<br><br>**AF-002: Mitigación de Fuerza Bruta (Intervención Automática)**<br>Durante el proceso de autenticación de cualquier usuario:<br>   1. El Sistema detecta múltiples intentos consecutivos de inicio de sesión con credenciales inválidas.<br>   2. Al superar el umbral máximo de fallos configurado, el Sistema bloquea automáticamente la cuenta por un periodo de tiempo determinado (ej. 15 minutos).<br>   3. El Sistema despacha una alerta de seguridad al correo del usuario notificando el bloqueo preventivo.<br>   4. El Sistema aísla el evento registrándolo como una anomalía de seguridad en la bitácora inmutable.<br><br>**AF-003: Recuperación de Contraseña (Autogestión)**<br>Si un usuario no autenticado solicita restablecer su acceso:<br>   1. El Usuario ingresa su correo en el portal y solicita la recuperación.<br>   2. El Sistema valida que la cuenta exista y no esté desactivada lógicamente.<br>   3. El Sistema genera un token de un solo uso, lo asocia a la cuenta y lo envía por correo electrónico.<br>   4. El Usuario ingresa una nueva contraseña a través del enlace seguro.<br>   5. El Sistema valida la política de complejidad y asegura que la contraseña no haya sido utilizada previamente por ese usuario.<br>   6. El Sistema actualiza la credencial de forma segura, invalida el token de recuperación y notifica el éxito de la operación. |
| **Postcondiciones**      | <ul><li>El ciclo de vida del usuario (creación, bloqueo o desactivación) se actualiza garantizando la protección de los recursos del sistema.</li><li>La revocación de accesos surte efecto inmediato sobre cualquier sesión activa.</li><li>Todas las mutaciones de identidad, intentos de vulneración y bloqueos quedan trazados criptográficamente para auditorías forenses.</li></ul>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
