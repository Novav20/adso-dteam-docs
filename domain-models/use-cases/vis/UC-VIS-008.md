# UC-VIS-008: Visualizar Capa de Permisos de Trabajo

## Plantilla de Caso de Uso

| **Elemento**             | **Detalle**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| :----------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ID**                   | UC-VIS-008                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Nombre**               | Visualizar Capa de Permisos de Trabajo                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Actor Principal**      | Inspector HSEQ                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **Actores Secundarios**  | Servicio de Sincronización en Tiempo Real                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Descripción**          | Permite al Inspector HSEQ superponer de forma dinámica una capa de seguridad con los permisos de trabajo activos sobre el Gemelo Digital. Los permisos se representan gráficamente bajo la filosofía de alto desempeño (HPHMI Grayscale) para identificar rápidamente operaciones simultáneas peligrosas (SIMOPS). El sistema detecta y alerta automáticamente sobre inconsistencias espaciales (permisos huérfanos).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **Precondiciones**       | <ul><li>El Inspector está autenticado en la plataforma con el rol autorizado de "Inspector HSEQ" [[TR-006]].</li><li>Existen permisos de trabajo en estado operativo (`APPROVED`) vigentes.</li><li>El plano interactivo de la instalación está cargado correctamente en el visor del usuario.</li></ul>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Flujo Principal**      | 1. El Inspector accede al visualizador del Gemelo Digital y activa el control de la capa "Permisos de Trabajo".<br>2. El Sistema recupera los permisos vigentes y ejecuta una validación de integridad referencial cruzando los identificadores de los activos (`TagNumber`) contra la metadata espacial del plano actual.<br>3. El Sistema renderiza los permisos válidos superponiendo iconos sobre los activos afectados. Utiliza codificación visual redundante (Color + Forma) basada en la filosofía HPHMI Grayscale [[TR-011]] para mitigar la fatiga cognitiva (ej. Trabajo en Caliente: Cuadrado Rojo).<br>4. El Inspector selecciona o posiciona el cursor sobre uno de los iconos renderizados.<br>5. El Sistema despliega una tarjeta de información emergente mostrando metadatos clave sin obstaculizar el plano: Tipo de Permiso, Contratista, Responsable HSEQ y Ventana Horaria.<br>6. El Inspector aplica filtros de visualización por categoría de riesgo (ej. "Espacio Confinado") y el Sistema actualiza la vista de forma instantánea.<br>7. El Sistema escucha eventos de dominio en tiempo real [[TR-010]]. Si un permiso es revocado, expirado o creado desde otro módulo, el Sistema actualiza dinámicamente el estado de la capa sin requerir recargar la interfaz. |
| **Flujos Alternativos**  | **AF-001: Enlace Roto Detectado (Permiso Huérfano)**<br>En el paso 2, si el sistema detecta un permiso activo cuyo activo asociado no existe en el plano actual o carece de coordenadas espaciales:<br>1. El Sistema omite el renderizado de dicho permiso en el mapa para evitar falsas localizaciones espaciales.<br>2. El Sistema genera una alerta silenciosa de "Integridad Comprometida" y añade automáticamente el registro a un panel lateral de "Fallos de Visualización".<br>3. El Inspector expande el panel, visualiza los datos del permiso huérfano y selecciona la acción de resolución para solicitar la actualización de la metadata espacial o la reasignación del Tag.<br><br>**AF-002: Interrupción del Servicio de Sincronización (Resiliencia)**<br>En el paso 7, si se pierde la conexión con el servicio de propagación en tiempo real:<br>1. El Sistema preserva la navegación general del Gemelo Digital sin bloquear al usuario.<br>2. El Sistema despliega un banner de advertencia prominente indicando que la capa opera con datos cacheados y muestra la marca de tiempo de la última sincronización confiable, asumiendo un estado conservador de seguridad operativa.                                                                                         |
| **Postcondiciones**      | <ul><li>La capa de permisos de trabajo se integra visualmente con el modelo espacial, mejorando la conciencia situacional (Situational Awareness).</li><li>Las inconsistencias geométricas quedan aisladas y reportadas para su corrección técnica.</li></ul>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
