# UC-VIS-008: Visualize Work Permits Overlay (Digital Twin)

## Use Case Template

| **Element** | **Detail** |
| :--- | :--- |
| **ID** | UC-VIS-008 |
| **Name** | Visualize Work Permits Overlay (Digital Twin) |
| **Primary Actor** | HSEQ Inspector |
| **Secondary Actors** | N/A |
| **Description** | Allows the spatial mapping and real-time visualization of high-risk operational permits (e.g., Hot Work, Confined Space) directly onto the interactive 2D/3D plant schematics (Visual Layer). By overlaying logical safety contexts onto the physical layout, it enhances operational situational awareness and strictly supports Simultaneous Operations (SIMOPS) control, mitigating interference risks. |
| **Preconditions** | <ul><li>The Inspector is authenticated in the platform with the authorized role of "HSEQ Inspector" [[TR-006]].</li><li>There are active work permits in operational status (`APPROVED`).</li><li>The interactive installation schematic is correctly loaded in the user's viewer.</li></ul> |
| **Main Flow** | 1. The Inspector accesses the Digital Twin viewer and activates the "Work Permits" layer control.<br>2. The System retrieves the active permits and executes a referential integrity validation by crossing the asset identifiers (`TagNumber`) against the spatial metadata of the current schematic.<br>3. The System renders the valid permits by overlaying icons on the affected assets. It uses redundant visual coding (Color + Shape) based on the HPHMI Grayscale philosophy [[TR-011]] to mitigate cognitive fatigue (e.g. Hot Work: Red Square; Heights: Blue Triangle).<br>4. The Inspector selects or hovers the cursor over one of the rendered icons.<br>5. The System displays a pop-up information card showing key metadata without obstructing the schematic: Permit Type, Contractor, HSEQ Responsible, Time Window, Status (Active / Expiring Soon) and associated LOTO reference (if applicable).<br>6. The Inspector applies visualization filters by risk category (e.g. "Confined Space") and the System updates the view instantly.<br>7. The System listens to domain events in real-time [[TR-010]]. If a permit changes status (e.g., enters the expiring soon window, is revoked, or a new one is created), the System dynamically updates the visual appearance of the icon without requiring an interface reload. |
| **Alternate Flows** | **AF-001: Broken Link Detected (SIMOPS Integrity Alert)**<br>In step 2, if the system detects an active permit whose associated asset does not exist in the current schematic or lacks spatial coordinates:<br>1. The System skips rendering the icon on the schematic to avoid false spatial localizations.<br>2. The System triggers a prominent visual safety alert ("SIMOPS Integrity Alert") and adds the record to the "Visualization Failures" side panel.<br>3. The Inspector expands the panel, analyzes the orphaned permit data (ID, Contractor, Expected Tag) and selects the resolution action to request the update of spatial metadata or asset reassignment.<br><br>**AF-002: Synchronization Service Interruption (Operational Resilience)**<br>In step 7, if the connection to the real-time propagation service is lost:<br>1. The System preserves general navigation of the Digital Twin without blocking the user.<br>2. The System displays a prominent warning banner indicating that the layer is operating with cached data and shows the timestamp of the last reliable synchronization, assuming a conservative state of operational safety. |
| **Postconditions** | <ul><li>The work permits layer is visually integrated with the spatial model, improving Situational Awareness.</li><li>Geometric inconsistencies and orphaned permits are highlighted prominently to avoid blind risks in SIMOPS.</li></ul> |
