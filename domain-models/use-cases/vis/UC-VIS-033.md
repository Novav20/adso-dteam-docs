# UC-VIS-033: Visualización Base e Inspección de Activos en 2D

## Plantilla de Caso de Uso

| **Elemento**             | **Detalle**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| :----------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ID**                   | UC-VIS-033                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **Nombre**               | Visualización Base e Inspección de Activos en 2D                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Actor Principal**      | Supervisor de Mantenimiento                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Actores Secundarios**  | Técnico de Mantenimiento, Inspector HSEQ, Sistema SCADA (Telemetría)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Descripción**          | Establece el lienzo interactivo base del Gemelo Digital. Permite a los usuarios cargar la representación espacial de una ubicación funcional, interactuar con las geometrías de los activos físicos y desplegar un panel contextual que sincroniza métricas operativas y telemetría en tiempo real, aplicando la filosofía de alto desempeño (HPHMI).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Precondiciones**       | <ul><li>El usuario está autenticado con permisos de lectura sobre el módulo de visualización [[TR-006]].</li><li>La ubicación funcional seleccionada cuenta con un plano interactivo y mapeo espacial (`SpatialMetadata`) configurado en el sistema.</li></ul>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Flujo Principal**      | 1. El usuario accede al módulo del Gemelo Digital y selecciona una ubicación funcional de la jerarquía de la planta.<br>2. El Sistema recupera la configuración espacial y renderiza el plano interactivo base utilizando la paleta de colores neutra (escala de grises) dictada por la filosofía HPHMI [[TR-011]].<br>3. El usuario selecciona la representación gráfica de un equipo específico en el plano interactivo.<br>4. El Sistema despliega un panel de inspección contextual que consolida los datos maestros del equipo (estado operativo, criticidad) y sus órdenes de trabajo activas.<br>5. El Sistema invoca el puerto de telemetría para suscribirse a las señales físicas del activo en tiempo real [[TR-010]].<br>6. El Sistema SCADA publica nuevas lecturas de los sensores del equipo.<br>7. El Sistema procesa la actualización asíncrona y refresca instantáneamente los valores en el panel de inspección sin interrumpir la navegación del usuario.                                                                                                       |
| **Flujos Alternativos**  | **AF-001: Inspección de Activo sin Mapeo Espacial**<br>Si el usuario localiza el activo a través del directorio de búsqueda textual en lugar del plano interactivo:<br>   1. El Sistema verifica si el activo posee metadatos espaciales vinculados al plano actual.<br>   2. Al detectar la ausencia de mapeo, el Sistema despliega el panel contextual con la información tabular, pero deshabilita el control de "Localizar en Plano".<br>   3. El Sistema alerta sutilmente: "Representación espacial no disponible para este activo."<br><br>**AF-002: Pérdida de Señal de Telemetría**<br>En el paso 6, si la conexión con el flujo de datos del SCADA se interrumpe:<br>   1. El Sistema detecta la caída de la suscripción en tiempo real.<br>   2. El Sistema congela los últimos valores recibidos, cambia su indicador visual a un estado de advertencia (ej. color gris/ámbar) y añade una marca de tiempo indicando: "Datos desactualizados. Conexión perdida."<br>   3. El Sistema reanuda la actualización dinámica automáticamente una vez se restablece el enlace. |
| **Postcondiciones**      | <ul><li>El usuario obtiene conciencia situacional centralizada sobre la posición física, estado lógico y comportamiento físico del activo.</li><li>El lienzo base queda inicializado y listo para soportar la superposición de capas de seguridad avanzadas (Permisos de Trabajo y LOTO).</li></ul>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
