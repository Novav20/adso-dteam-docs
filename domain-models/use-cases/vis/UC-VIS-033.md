# UC-VIS-033: Navigate Interactive Digital Twin (Geometric and Semantic Zoom)

## Use Case Template

| **Element** | **Detail** |
| :--- | :--- |
| **ID** | UC-VIS-033 |
| **Name** | Navigate Interactive Digital Twin (Geometric and Semantic Zoom) |
| **Primary Actor** | System User (Generic) |
| **Secondary Actors** | Telemetry Service (IoT) |
| **Description** | Provides the foundational interactive interface for spatial navigation and asset exploration within the plant. Employs a dual-zoom approach (Geometric for continuous scaling, Semantic for dynamic detail disclosure) based on HPHMI principles to manage cognitive load, allowing users to intuitively discover technical specifications, active work context, and live telemetry data from physical assets. |
| **Preconditions** | <ul><li>The user is authenticated with read permissions on the visualization module [[TR-006]].</li><li>The selected functional location has an interactive schematic and spatial mapping configured in the system.</li></ul> |
| **Main Flow** | 1. The user accesses the Digital Twin module and selects a functional location from the plant hierarchy.<br>2. The System retrieves the spatial configuration and renders the base interactive schematic using the neutral HPHMI palette [[TR-011]]. The canvas supports dual navigation combining **Geometric Zoom** (fluid SVG viewport scaling via mouse wheel or touch gestures) and **Semantic Zoom** (automatic information density switching based on scale thresholds: the zoomed-out view shows only equipment silhouettes and critical alarms; the zoomed-in view reveals TagNumber identifiers, connection ports, and process variables).<br>3. The user navigates the schematic (via panning and zooming) and selects the graphical representation of a specific equipment unit.<br>4. The System deploys a contextual inspection panel that consolidates the equipment's master data (Tag, lifecycle status, criticality), active Work Orders count, and informative security status indicators (summary of active LOTO and Permits).<br>5. The System requests a subscription to the asset's real-time physical telemetry channel [[TR-010]].<br>6. The Telemetry Service publishes the equipment's sensor readings.<br>7. The System processes the asynchronous update and refreshes the values in the inspection panel (showing value, unit, and normal operating ranges) without interrupting the user's navigation. |
| **Alternate Flows** | **AF-001: Inspection of Asset without Spatial Mapping**<br>If the user locates the asset through the textual search directory instead of the interactive schematic:<br>   1. The System checks if the asset has spatial metadata linked to the current schematic.<br>   2. Upon detecting the absence of mapping, the System deploys the contextual panel with tabular information, but disables the "Locate on Schematic" control.<br>   3. The System indicates via an informative badge: "Spatial Mapping Pending for this asset."<br><br>**AF-002: Telemetry Signal Loss (Redundant Coding)**<br>In step 6, if the connection to the telemetry data stream is interrupted:<br>   1. The System detects the drop in the real-time subscription.<br>   2. The System freezes the last received readings, applies a warning indicator via redundant Shape + Color coding (warning symbol and amber indicator) according to ISA-101 / WCAG 2.1 AA, and displays the disconnection timestamp: "Stale Data. Connection Lost."<br>   3. The System automatically resumes the dynamic update once the link is restored. |
| **Postconditions** | <ul><li>The user gains centralized situational awareness of the asset's physical position, logical state, and physical behavior with HPHMI context.</li><li>The base canvas is initialized and ready to support the overlay of advanced security layers (Work Permits and LOTO).</li></ul> |
| **Associated Requirements** | FR-598, FR-599, FR-600, FR-601, FR-602, NFR-603, NFR-604, NFR-605, [[TR-010]], [[TR-011]] |
