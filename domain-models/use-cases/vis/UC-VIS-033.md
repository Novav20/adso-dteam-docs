# UC-VIS-033: Inspeccionar Activos sobre el Plano Base 2D

## Plantilla de Caso de Uso

| :----------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ID**                   | UC-VIS-033                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Nombre**               | Visualización Base e Inspección de Activos en 2D                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Actor Principal**      | Supervisor de Mantenimiento                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Actores Secundarios**  | Técnico de Mantenimiento, Inspector HSEQ, Servicio de Telemetría (SCADA)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Descripción**          | Establece el lienzo interactivo base del Gemelo Digital. Permite a los usuarios cargar la representación espacial de una ubicación funcional, interactuar con las geometrías de los activos físicos y desplegar un panel contextual que sincroniza métricas operativas y telemetría en tiempo real, aplicando la filosofía de alto desempeño (HPHMI).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Precondiciones**       | <ul><li>El usuario está autenticado con permisos de lectura sobre el módulo de visualización [[TR-006]].</li><li>La ubicación funcional seleccionada cuenta con un plano interactivo y mapeo espacial configurado en el sistema.</li></ul>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Flujo Principal**      | 1. El usuario accede al módulo del Gemelo Digital y selecciona una ubicación funcional de la jerarquía de la planta.<br>2. El Sistema recupera la configuración espacial y renderiza el plano interactivo base utilizando la paleta neutra HPHMI [[TR-011]]. El lienzo soporta navegación dual combinando **Zoom Geométrico** (escalado fluido del viewport SVG mediante rueda de ratón o gestos táctiles) y **Zoom Semántico** (conmutación automática de densidad de información según umbrales de escala: la vista alejada muestra solo siluetas de equipos y alarmas críticas; la vista cercana revela identificadores TagNumber, puertos de conexión y variables de proceso).<br>3. El usuario navega por el plano (mediante paneo y zoom) y selecciona la representación gráfica de un equipo específico.<br>4. El Sistema despliega un panel de inspección contextual que consolida los datos maestros del equipo (Tag, estado de ciclo de vida, criticidad), conteo de Órdenes de Trabajo activas e indicadores informativos de estado de seguridad (resumen de LOTO y Permisos vigentes).<br>5. El Sistema solicita la suscripción al canal de telemetría física del activo en tiempo real [[TR-010]].<br>6. El Servicio de Telemetría publica las lecturas de los sensores del equipo.<br>7. El Sistema procesa la actualización asíncrona y refresca los valores en el panel de inspección (mostrando valor, unidad y rangos de operación normales HPHMI) sin interrumpir la navegación del usuario.                                                                                             |
| **Flujos Alternativos**  | **AF-001: Inspección de Activo sin Mapeo Espacial**<br>Si el usuario localiza el activo a través del directorio de búsqueda textual en lugar del plano interactivo:<br>   1. El Sistema verifica si el activo posee metadatos espaciales vinculados al plano actual.<br>   2. Al detectar la ausencia de mapeo, el Sistema despliega el panel contextual con la información tabular, pero deshabilita el control de "Localizar en Plano".<br>   3. El Sistema indica mediante un distintivo informativo: "Mapeo Espacial Pendiente para este activo."<br><br>**AF-002: Pérdida de Señal de Telemetría (Codificación Redundante)**<br>En el paso 6, si la conexión con el flujo de datos de telemetría se interrumpe:<br>   1. El Sistema detecta la caída de la suscripción en tiempo real.<br>   2. El Sistema congela las últimas lecturas recibidas, aplica un indicador de advertencia mediante codificación redundante de Forma + Color (símbolo de advertencia e indicador ámbar) según ISA-101 / WCAG 2.1 AA, y muestra la marca de tiempo de la desconexión: "Datos Desactualizados. Conexión Perdida."<br>   3. El Sistema reanuda la actualización dinámica automáticamente una vez se restablece el enlace. |
| **Postcondiciones**      | <ul><li>El usuario obtiene conciencia situacional centralizada sobre la posición física, estado lógico y comportamiento físico del activo con contexto HPHMI.</li><li>El lienzo base queda inicializado y listo para soportar la superposición de capas de seguridad avanzadas (Permisos de Trabajo y LOTO).</li></ul>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
