\section{Especificación de Historias de Usuario}

Esta sección detalla las Historias de Usuario que sirvieron como base para la elicitación de los requisitos del sistema. Cada historia representa una unidad de valor funcional desde la perspectiva de un actor específico del Gemelo Digital.

\subsection*{Nomenclatura y Trazabilidad}
Se ha implementado un sistema de identificación global único para garantizar la trazabilidad total. Cada historia posee un código compuesto por el prefijo del módulo funcional (\textbf{MTTO}, \textbf{INV}, \textbf{VIS}, \textbf{ADM}) seguido de un consecutivo numérico único en todo el proyecto.

\subsection*{Estimación de Esfuerzo (Complejidad)}
Para la valoración de la complejidad de cada historia, se ha utilizado la escala de \textbf{Fibonacci} estándar en metodologías ágiles (Cohn, 2004). Los puntos reflejan una combinación de esfuerzo, complejidad técnica y riesgo asociado:

\begin{itemize}[leftmargin=1.5em, nosep]
    \item \textbf{1 - 2 Puntos:} Tareas triviales o de muy baja complejidad (ajustes menores de interfaz).
    \item \textbf{3 Puntos:} Funcionalidades estándar con baja incertidumbre (operaciones CRUD básicas).
    \item \textbf{5 Puntos:} Funcionalidades con lógica de negocio compleja o integraciones industriales.
    \item \textbf{8 - 13 Puntos:} Alta complejidad técnica, requerimientos de seguridad críticos o alta incertidumbre (investigación técnica requerida).
\end{itemize}
